What it is

  • Decision layer — every AI agent decision is hashed with its inputs, outputs, model id and timestamp. REAL
  • Merkle provenance — decisions batch into a Merkle tree with a single 32-byte root. REAL
  • BOT Chain anchor — the root is committed on-chain as a public witness. ON-CHAIN
  • ZK add-on — Groth16 proofs for selected decision predicates (opt-in). REAL
  • Client-side verify — a browser can re-derive the root without any API call. REAL

How it works

  1. Your agent emits a decision — request/response/model/ts.
  2. BOT Chain Prover hashes it canonically (SHA-256), redacting PII by policy.
  3. Hashes batch into a Merkle tree; the root anchors on BOT Chain.
  4. Anyone with the JSON receipt can re-derive the root — no server trust.
